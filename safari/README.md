## 起動と確認

1. このフォルダを保存し、macOS Safariで `index.html` を直接開きます。
   アドレスが `file://` であることを確認します。
2. 日本語名、多階層、空フォルダ、PDF、PNG、UTF-8テキストを含む使い捨ての検証用フォルダを用意します。
3. フォルダを選択し、一覧の `ルート/サブフォルダ/ファイル名` が実ファイルと一致するか確認します。
   `webkitdirectory` プロパティの存在だけでは、選択の実動作を確認したことになりません。
4. ファイル名を選んでPDF・画像・テキストを確認します。
   PDFの描画成功は自動判定せず目視で確認します。
5. 保存ボタンを押し、トランザクション完了ログの保存マーカーを控えます。
6. SafariをCmd+Qで完全終了し、同じプロファイル・同じ配置のHTMLを再度開きます。
   マーカーの一致を確認します。**以前のファイル一覧・プレビューは表示されないこと**も確認します。
7. フォルダを再選択してから一覧・プレビューを再確認します。
   実ファイルを追加・削除して再選択し、最新の一覧だけが表示されるか確認します。
8. 再選択のキャンセル、読取不能ファイル、フォルダの移動も確認します。
   再選択開始時に旧一覧を隠し、失敗時は保存メタデータを置換しません。
   保存待ちの再選択でも古い保存を中断します。保存直前にも読取可否を再確認します。
   Safariの版によってcancelイベントがなくても、選択開始時に旧一覧は隠れます。

ログにはSafariのUser-Agent・起動方式・API結果が表示されます。
OS/Safari版、操作、期待値、実際の結果、ログ・画面証跡を記録してください。
ログには選択した相対パスが含まれるので、共有には検証用フォルダを使ってください。

## ブラウザの制約

- Safariは `showDirectoryPicker` と永続ディレクトリハンドルを提供しません。
  このPoCは `<input type="file" webkitdirectory>` と `File.webkitRelativePath` を検証します。
- 選択した時点のファイル一覧です。無操作の自動再走査・監視はできません。
  **Edgeと同等の自動更新は未達成です。**
- 空フォルダやブラウザが省略した項目の完全な列挙を保証できません。
  PoCは取得できたファイルからのパスをそのまま表示します。
  本番版の隠しファイル除外・検索仕様はまだ実装していません。
- Safariは同じ名前のフォルダが同じ実体であることを保証する識別子や絶対パスを公開しません。
  名前だけで以前のルートと同一と判断してはいけません。
- IndexedDBは選択一覧のメタデータだけを専用DB
  `file-search-safari-phase0-v1` に保存します。本文・File・ハンドルは保存しません。
  起動時は照合マーカーのみ読み出し、古い一覧を結果として表示しません。
  キャンセル・読取失敗でも保存済みデータを削除しません。
- 保存成功はトランザクション完了後に記録します。保存禁止・容量不足・ブロックは失敗として記録します。
  `file://` 保存領域、プライベートブラウズ、プロファイル、HTMLの移動、
  ブラウザデータ削除による寿命の違いは実機確認が必要です。
- 取得したFileが後で読取不能になる場合もあります。プレビューはその都度読み、
  失敗時は旧プレビューを表示しません。再読込やSafari再起動後には必ず明示的な再選択が必要です。
- PDFはネイティブ表示、画像は対応するラスター形式のみ、その他は先頭16 KiBの
  UTF-8/Shift-JIS候補です。切出し末尾の未完文字を保留して誤った文字コード判定を避けます。
  Officeやバイナリの表示は保証しません。
  HTMLはテキストとして扱います。PDFやHEIC/TIFF等の対応可否はSafariに依存します。
- このPoCに更新件数や進捗表示はありません。
- 実行時はPython、Node、localhost、サーバー、拡張、CDN、ビルド、外部通信を必要としません。
  スクリプトとスタイルはHTMLに内包しています。

### 開発用macOS CI

`.github/workflows/safari-phase0.yml` は、このPRのSafari関連変更で
`macos-15` のインストール済みSafariとAppleの `safaridriver` を使用します。
ドライバーは `safari/check_safari.py`（Python標準ライブラリのみ）です。
同じセッション内での保存マーカー再読出しと旧一覧非表示を確認してから、Safariを完全終了します。
Safariバージョン、チェック結果、初回・再読込・再起動後のアプリログと画面、失敗時のドライバーログを
Actions artifactへ14日保存します。既存Python回帰テストも実行します。

CIだけでWebDriverを有効にし、localhostのWebDriver制御接続を使います。
**アプリ配信のWebサーバーは起動しません。アプリはfile://で開きます。**
ドライバー、Python、WebDriver有効化はアプリの実行条件ではありません。
Safariのセキュリティ設定緩和、代替Chromium/WebKit、ファイル選択APIのモック、
自動フォルダ権限付与は使いません。

CIの保存データは明示的に合成メタデータと記録します。
実FileListやネイティブフォルダアクセスの証拠として扱いません。
自動操作プロファイルの寿命により再起動照合が失敗した場合も、
通常プロファイルでの保存不可と断定せず、ログを残して手動確認を継続します。

### 自己精査による修正と検証

- 保存待ち中の再選択で、前の選択が後から保存される競合を修正。
  DBオープン完了時の世代確認と、開始済みトランザクションの中断を追加。
- 保存直前の読取確認、重複保存の抑止、プレビューの読取失敗時の一覧非表示を追加。
- 先頭16 KiBがUTF-8日本語文字の途中で終わる場合のShift-JIS誤判定を修正。
- `poc-tests.cjs` は模擬DOM・File読取・IndexedDBトランザクション順序を使う12ケース。
  開発環境のJavaScript実行ツールで12件成功。修正前は保存競合のケースで失敗。
  この実行では限定的な模擬UTF-8デコーダーを使用しており、ネイティブの文字コード処理は未検証。
  CIではNodeのネイティブTextDecoderで同じテストを実行する構成。
- 実行手順（開発用のみ）: `node safari/poc-tests.cjs`。
  アプリの実行にはNodeは不要。模擬テストはSafari実機受入の代替ではない。
- **以前の「CI実行記録0件」という報告を訂正**。
  当初の照会ツールはPRイベントのみを対象としていた。
  全イベントの照会では、旧HEADに
  [失敗記録](https://github.com/g00dk0nd0u/File_search_DB/actions/runs/40342837142)
  が存在し、ジョブは0件だった。
  ジョブ設定での `runner.temp` 参照をやめ、最初のステップで `RUNNER_TEMP` と
  `GITHUB_ENV` から証跡ディレクトリを設定する形へ修正した。
  さらに、[修正直後のCI](https://github.com/g00dk0nd0u/File_search_DB/actions/runs/40345168456)
  は緑表示でも、SafariドライバーがHTTP 500で停止していた。
  既定シェルのパイプラインが `tee` の終了値を返して失敗を隠していたため、
  `shell: bash` を明示し `-eo pipefail` を有効にした。
  WebDriverの失敗応答本文とコマンドも記録する。
  このCIで確認できた成功は模擬テスト12件とPython回帰55件のみ。
  Safari 26.6.1 / macOS 15.7.9のセッション作成までは観測したが、
  file://起動・IndexedDB・再起動保存の成功は未確認。
  以降のCI結果はPR・Issueに追記し、緑表示だけで成功と推定しない。
